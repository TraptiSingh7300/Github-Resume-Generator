# 🚀 GitHub Resume Generator

[Live Link](https://traptisingh7300.github.io/Github-Resume-Generator/)

A lightweight, responsive web application that instantly converts any public GitHub profile into a clean, developer-focused resume using the **GitHub REST API**.

## ✨ Features

* **Instant Profile Fetching:** Retrieves user details, bio, location, company, and follower metrics dynamically.
* **Skill Badges:** Automatically identifies languages and topics from top repositories to display key skills.
* **Top Projects Highlight:** Automatically sorts and presents the top 6 starred, non-forked repositories.
* **Zero Backend / Tokenless:** Works entirely in the client-side browser using GitHub's public REST API—no personal access tokens or server setups required.
* **GitHub Dark Theme UI:** Sleek design inspired by GitHub's dark aesthetic.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3
* **Logic & API:** Pure JavaScript (ES6+ `async/await`, `fetch` API)
* **API:** [GitHub REST API v3](https://docs.github.com/en/rest)

## 🚀 Quick Start

   ```bash

   cd YOUR_REPOSITORY_NAME

Run Locally
Simply open index.html in any modern web browser (Chrome, Firefox, Edge, Safari). No installation or local server required!

🌐 Deploying to GitHub Pages
You can host this project online for free in less than a minute:

Push your code to your GitHub repository.

Go to your repository Settings → Pages (on the left menu).

Under Build and deployment → Branch, select main (or master) and click Save.

Your site will be live at https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/!
